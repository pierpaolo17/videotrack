# Historical engineering records

The files in this directory preserve audits and implementation notes from early 1.4.x development. They are retained only to reconstruct historical decisions.

They are **not** the maintenance contract for the current plugin and may mention code, versions, file counts, APIs or browser behaviour that no longer exists. Use the numbered documents in the parent directory (`00_INDEX.md` through `13_CONSOLIDATION_AUDIT.md`) as the current source of truth.
