# Documentazione Videotrack

Questa cartella contiene la documentazione tecnica aggiornata del plugin Videotrack.

## Documenti operativi

1. `01_DEVELOPER_GUIDE.md` - workflow di sviluppo, regole patch e checklist.
2. `02_ARCHITECTURE.md` - architettura del plugin e responsabilità dei componenti.
3. `03_FILE_INVENTORY.md` - inventario completo dei file.
4. `04_FUNCTION_INVENTORY.md` - inventario funzioni PHP e JavaScript AMD.
5. `05_VARIABLE_INVENTORY.md` - inventario variabili PHP e JavaScript AMD rilevate staticamente.
6. `06_RUNTIME_FLOWS.md` - flussi runtime principali.
7. `07_BUILD_TEST_RELEASE.md` - build, test, release e troubleshooting.
8. `08_LESSONS_LEARNED.md` - regole apprese durante le iterazioni di sviluppo.
9. `09_DOCUMENTATION_AUDIT.md` - audit della copertura documentale e checklist per aggiornamenti futuri.
10. `10_BOOKMARKS_AND_ANALYTICS.md` - modello dati, runtime, privacy, report e validazione completa dei segnalibri.

11. `11_INTEGRITY_AND_FOCUS.md` - segnali di integrità, controlli anti-cheat del focus, limiti privacy e matrice di regressione.

## Documenti storici

I documenti storici di audit rimangono disponibili in questa cartella. Sono utili per ricostruire decisioni passate, ma la fonte aggiornata per la manutenzione corrente sono i file numerati da `00_` a `11_`.
