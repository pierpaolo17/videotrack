# Documenti tecnici storici

I file di questa cartella conservano audit e note di implementazione risalenti alle prime release 1.4.x. Sono mantenuti esclusivamente per ricostruire decisioni storiche.

**Non** costituiscono il contratto di manutenzione del plugin corrente e possono citare codice, versioni, conteggi, API o comportamenti browser non più validi. La fonte aggiornata è la documentazione numerata nella cartella superiore (`00_INDEX.md`–`13_CONSOLIDATION_AUDIT.md`).
