# mod_videotrack — Technical plugin structure
Document updated for release **1.4.125**. It replaces obsolete historical sections in the previous `struttura_tecnica.md` with an operational snapshot of the real plugin structure.
## 1. Purpose of this document
This guide documents the plugin structure, the purpose of the main files, and the inventory of PHP/AMD functions in the current baseline. It is not a changelog: historical details are kept only in the separate documents listed below.

## 5. Database and persistent data
Tables are defined in `db/install.xml` and updated by `db/upgrade.php`. The data model separates the activity instance, raw segments, aggregated state, reaction definitions, and note/reaction events. Interval merge and simplification logic is concentrated in `classes/local/tracker.php`, while retention and anonymisation are concentrated in `classes/local/privacy_manager.php`.

## 6. AMD layer and build rules
Files in `amd/src/` are source files. The matching `amd/build/*.min.js` and `*.map` files are generated artefacts. Any patch changing `amd/src/*` must actually run `grunt amd` in the validated Moodle environment, check `git status`, and include every modified generated file.
